# MetaManifold v0.2.0

MetaManifold is a self-hosted web application for amplicon metabarcoding, built
around eukaryotic communities. It runs DADA2 and swarm side by side, assigns
taxonomy against PR2 or another reference database, places ASVs on reference
trees, and carries the results through statistics to publication figures. DADA2
and phylogeny stages can run on a remote server over SSH.

This release adds `glmGamPoi` to differential abundance, extends the figure and
tree tools, hardens the server's browser headers, and moves the project to
per-file licensing.

MetaManifold currently works with Illumina-style paired-end amplicons and tests
differential abundance between two conditions at a time. The server has no login
and is designed for one user or a trusted group. The README sets out
[what is and is not supported](https://github.com/JoshuaJewell/MetaManifold-WebUI/#is-it-right-for-your-project).

## New in this release

### Differential abundance

- `glmGamPoi` is now available as a dispersion option for the negative-binomial
  GLM, using its shared dispersion trend and quasi-likelihood F-test. The
  default `glm_nb` is unchanged.
- Taxa with zero reads are kept out of the shared `glmGamPoi` fit.
- A null-calibration reproducer is included in `bench/glm_nb_calibration/`, and
  per-method calibration summaries are fixed.

### Figures and trees

- Figures can now include text and image panes.
- Tree labels can be set in italics.
- The tree viewer shows each placement's best likelihood weight ratio and can
  save a threshold with the view. Missing weights stay missing, and no best
  location is assigned from incomplete weights.

### Fixes

- Comparison bars and analysis tabs now work correctly for grouped runs.

### Security

- Default browser response headers are hardened, including on live progress
  streams, without breaking report embedding across split-origin deployments.

### Testing

- CI now runs DADA2 taxonomy against a subset of PR2, so the eukaryotic reference
  path is tested with real database content.
- Per-run checks in the threaded pipeline integration test now count towards the
  test totals, and a failure names its run.

## Licensing has changed

MetaManifold now uses per-file licensing, marked with SPDX headers and following
the [REUSE](https://reuse.software) specification:

| Files | Licence |
|---|---|
| Server, and the tests that exercise it | AGPL-3.0-or-later |
| Core, pipeline, analysis, frontend and tooling | MPL-2.0 |
| Documentation | CC BY-SA 4.0 |
| Lockfiles and generated manifests | CC0-1.0 |

Using MetaManifold, including for published research, places no new obligations
on you. The change makes it easier to reuse parts of it: pipeline and analysis
code can go into other tools under MPL-2.0, and changes to those files stay open.
If you run a modified server for other people, the AGPL requires you to offer
them its source.

The project as shipped remains AGPL-3.0-or-later, because the server is.
Published releases, including v0.1.0, stay under their original terms.

## Upgrading

```bash
git pull
bash install.sh --update
```

`glmGamPoi` is a new pinned R dependency.

## Documentation

The README is now a short introduction, and the reference material has moved to
[`docs/guide/`](https://github.com/JoshuaJewell/MetaManifold-WebUI/tree/main/docs/guide).

## Platforms

- **Linux:** supported and tested.
- **Windows:** supported through WSL. Native Windows is not supported.
- **macOS:** supported by the installer but not routinely tested. Please report
  problems as issues.
