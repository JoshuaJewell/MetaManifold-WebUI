# MetaManifold v0.1.0

## What MetaManifold is

MetaManifold is a self-hostable platform for amplicon microbiome analysis by
metabarcoding. It composes established command-line tools of the field into a
single configurable pipeline, stores per-run results in DuckDB, and presents
them through an interactive web interface. It gives particular attention to
eukaryotic data (18S amplicons classified against PR2) and treats comparison
across sequencing runs as a priority operation.

This first release exists to provide a fixed, dependency-pinned point that
other researchers can install, run, reproduce, and cite in their own work.

## Highlights

- **Pipeline.** cutadapt primer trimming, then DADA2 (ASVs) and swarm (OTUs)
  side by side, with vsearch and DADA2 taxonomy assignment, cd-hit-est, and a
  final merge and filter into per-run DuckDB results. FastQC and MultiQC
  provide raw-read QC.
- **Phylogenetic placement.** A shared library of reference trees (MAFFT,
  trimAl, IQ-TREE), onto which a study's ASVs are placed (MAFFT
  `--addfragments`, RAxML EPA, gappa), with alignment QC at each step.
- **Web interface.** Every setting is editable at any level of the
  instance/study/group/run cascade, with stale stages flagged when settings
  change. Runs and individual stages are launched from the browser with live
  progress. It also has a filterable results explorer with saved presets and
  `.xlsx` export, and an interactive tree viewer for Newick and jplace files.
- **Analysis.** Alpha diversity with significance testing, taxonomic and
  organism-category composition, Euler and UpSet overlap, NMDS, PERMANOVA (each
  term tested separately) with PERMDISP, and differential abundance between two
  conditions (a negative-binomial GLM, or Welch's t-test on centred
  log-ratios). A test that could not run is reported as such, never as a null
  result.
- **Figures and report.** Analysis charts laid out on a page and exported.
- **Remote execution.** Any of the DADA2 and phylogeny stages can be sent to a
  server over SSH.
- **Provenance.** Each run records the configuration, tool versions and
  database hashes behind every stage in `attestation.yml`.
- AGPL-3.0 licensed; CI on GitHub Actions; coverage tracked on Codecov.

## Platforms

- **Linux:** supported and tested.
- **Windows:** supported through WSL, tested. Native Windows is not supported.
- **macOS:** the installer supports it and it is expected to work, but it has
  not been tested for this release. Please report problems as issues.

## Reproducibility

- Julia dependencies are pinned in `Manifest.toml`.
- R dependencies (DADA2, vegan, MASS, zCompositions and their dependencies)
  are pinned in `renv.lock` and restored by the installer.
- External tool versions are pinned in `config/defaults/tool_versions.yml`.
- Citation metadata is in `CITATION.cff`.

## How to cite

This release is archived on Zenodo; cite the concept DOI minted for the tag
together with the upstream tool citations listed under `references:` in
`CITATION.cff`.
